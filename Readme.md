1️⃣ Difference between var, let, and const:
var is the older way to declare variables in JavaScript and allows both redeclaration and updating of its value, which can sometimes lead to unexpected behavior. let is a newer approach that allows the variable to be updated but prevents redeclaration within the same scope, making the code safer and more predictable. const is used to declare variables whose value should not change; it cannot be updated or redeclared, making it ideal for constants and fixed references.

2️⃣ Spread operator (...):
The spread operator is a syntax that allows you to expand or copy the elements of an array or object. It is very useful when you want to merge arrays, copy objects, or pass multiple values as arguments without mutating the original data.

3️⃣ Difference between map(), filter(), and forEach():
The map() method creates a new array by transforming each element of the original array according to a provided function. filter() returns a new array containing only the elements that satisfy a certain condition. On the other hand, forEach() executes a function for every element in the array but does not return a new array, making it suitable for operations like logging or updating external variables.

4️⃣ Arrow function:
An arrow function is a concise way to write functions in JavaScript. Instead of using the function keyword, it uses the => syntax, which makes the code shorter and preserves the this context from its surrounding scope.

5️⃣ Template literals:
Template literals provide an easy way to create strings, especially when you want to include variables or expressions inside them. Using backticks (`) instead of quotes, you can embed variables directly within a string using the ${}` syntax, making string construction much cleaner and readable.
